04 / Usage

✓ Recommended

  • Use signature logo for store and launch materials.
  • Use a simplified version at 16 px.
  • Leave clear space equal to at least 12% of icon width.
  • Use Inter for interface body copy.

✕ Avoid

  • Skewing or horizontally stretching the logo.
  • Mixing unapproved extra gradients.
  • Placing the logo on high-contrast photo details without space.
  • Replacing brand wordmark with unrelated fonts.

05 / Implementation

Use the assets in 03_Chrome_Extension for the browser store and extension manifest, 04_Favicon_and_PWA for website assets, and 06_Design_Tokens for CSS and JSON values. File paths in example manifests must be adjusted before deployment.
